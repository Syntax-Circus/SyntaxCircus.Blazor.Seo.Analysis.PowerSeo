Planned MIT browser companion for `SyntaxCircus.Seo.Analysis`, using selected Power SEO checks in a self-hosted Web Worker. Targets interactive Blazor Server and WebAssembly without a separate Node service or React dependency.

The repository currently contains the [design for review](docs/superpowers/specs/2026-10-15-power-seo-browser-design.md); the runtime package is not implemented or published yet. Build and Tests badges will become active when its workflow is added. The Tests badge tracks that workflow's test gates, not a fixed count.

Initial scope: subheading distribution, transition words and word complexity. The C# core retains baseline ownership and applicability. See [execution status](docs/execution.md).
